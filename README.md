---

Software engineer in Guayaquil, Ecuador. I work across data pipelines, internal operational systems, and full-stack web applications, with a strong preference for reliable, predictable architectures that run quietly without midnight surprises.

Day to day, most of my work is about taking messy operational workflows and scattered data, putting clean models behind them, and automating the manual steps away. Outside of work, I build side projects, record coding tutorials in English, and transition deeper into core backend and systems engineering.

### Stack

**Day to day:**
- **Python** — Django, FastAPI, automated ETL scripts, data modeling, and internal tools.
- **TypeScript / React** — Next.js (App Router), Tailwind CSS, and responsive web interfaces.
- **PostgreSQL / SQL** — Relational schema design, query optimization, and reporting datasets.
- **Docker & Linux** — Containerized environments, Nginx reverse proxies, and reproducible local setups.

**Currently learning & building with:**
- **Rust** — Backend APIs with Axum and SQLx, strict type safety, and fighting the borrow checker until it compiles cleanly.
- **WebAssembly** — Experimenting with running sandboxed Python directly in the browser using Pyodide Web Workers.

### Principles

- Schema migrations should always be reversible and idempotent.
- Compile-time correctness (Rust / TypeScript) saves hours of runtime firefighting.
- If a service genuinely does not need a heavyweight infrastructure layer, keep it simple.
- Code should be written for the engineer who has to debug it at 2am six months from now—especially when that engineer is me.
